# 🔐 强密码生成器 (Password Generator)

这是一个简单但实用的 Python 小工具，用于生成安全的随机密码。
适合不想安装额外软件，只想快速生成复杂密码的用户。

## ✨ 功能特点

- **安全**：组合大写字母、小写字母、数字和特殊符号。
- **灵活**：支持自定义密码长度。
- **便携**：无需安装，直接在 GitHub Codespaces 或任何 Python 环境运行。

## 🚀 如何使用 (无需安装软件)

1. 点击仓库右上角的绿色按钮 **<> Code**。
2. 选择 **Codespaces** 并创建一个新环境。
3. 等待终端加载完成后，输入以下命令并回车：

   ```bash
   python main.py
